# 運彩 101｜首頁與 MLB 單場比賽頁原型（V1.2.1）

純 HTML / CSS / JavaScript，無後端、無 API、無資料庫、無建置步驟。ZIP 與 GitHub 倉庫（yaoshengmarketing-prog/101）是同一份扁平目錄結構。

## 如何開啟

1. 解壓縮後，直接雙擊 `index.html`（本日比賽首頁）。
2. 首頁 9/22「今天」的 **國民 @ 老虎** 卡片按「查看比賽資料 →」進入 `game.html?pk=824221`（單場頁；pk 找不到會顯示提示）。
3. 手機版：把瀏覽器縮到 375–430px 寬，或用 DevTools 的裝置模式。

線上版：https://yaoshengmarketing-prog.github.io/101/ ｜ 單場頁：https://yaoshengmarketing-prog.github.io/101/game.html?pk=824221

Google Fonts 連不到時會自動退回系統字型，不影響功能。

## 打線狀態（全站統一，五種值）

`Game.lineup` 與 `games[pk].lineup` 一律使用：

| 值 | 首頁卡片／單場頂部／打線區顯示 |
|---|---|
| `none` | 預估打線尚未完整 |
| `partial` | 預估打線尚未完整 |
| `estimate` | 預估打線已建立 |
| `official` | 官方打線已確認 |
| `late` | 臨場異動 |

打線區內另有細分狀態（初步預估／多來源共識／官方確認／臨場異動）與「原型預覽：切換狀態」下拉；切換只影響打線區的示範預覽，不改變上面的統一狀態。

## 資料狀態標記

| 標記 | 意思 |
|---|---|
| 已確認 | 官方已公布 |
| 預計 | 尚待確認（預計先發） |
| 預估非官方 | 預估打線，非 MLB 官方公布 |
| 原型示範 | 示範資料：**全部盤口**、打線的首次發布時間／來源共識／備選名單、官方確認與臨場異動版本 |
| 資料不足 | 原型未取得或無有效樣本，**不以 0 填補** |

戰績、先發投手、打擊、牛棚、近五場、打序名單是 2026/09/21 15:40（台北）從 MLB 官方數據抓的一次性快照，**不是即時資料**；畫面上已標示。
